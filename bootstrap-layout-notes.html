Bootstrap Layout Notes

Grid system, containers, breakpoints, and utilities — all in one place.

01 The Big Idea — What Bootstrap Actually Does

Bootstrap gives you a pre-built CSS system so you stop writing layout CSS from scratch. It handles responsiveness automatically using a 12-column grid. Every layout you build will be based on dividing those 12 columns.

You add classes to your HTML — Bootstrap's CSS file does the rest. No custom CSS needed for basic layouts.

<!-- Link Bootstrap in <head> -->
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.0/dist/css/bootstrap.min.css">
02 Containers — The Wrapper Everything Lives In

Every Bootstrap layout starts with a container. It centers your content and adds padding on the sides.

Class Behavior
.container Fixed width — snaps to breakpoint widths. Most common.
.container-fluid Always 100% width. Edge-to-edge layout.
.container-md Fluid below md, fixed from md and up. (Works for any breakpoint.) 
<div class="container">
  <!-- your rows and columns go here -->
</div>
03 The 12-Column Grid — Row → Col Pattern

Always: .container → .row → .col-*. Columns go inside rows, rows go inside containers. Break this order = broken layout.

<div class="container">
  <div class="row">
    <div class="col-4">Left</div>
    <div class="col-4">Middle</div>
    <div class="col-4">Right</div>
  </div>
</div>

04 Breakpoints — Making It Responsive

Bootstrap is mobile-first. Breakpoints activate at the given size and up. Stack multiple breakpoint classes on one element.

PrefixScreen SizeUse Case
col-All sizes (< 576px)Mobile default
col-sm-≥ 576pxLarge phones
col-md-≥ 768pxTablets
col-lg-≥ 992pxLaptops
col-xl-≥ 1200pxDesktops
col-xxl-≥ 1400pxWide screens
 
<!-- Full width on mobile, half on tablet, 1/3 on desktop -->
<div class="col-12 col-md-6 col-lg-4">Card</div>
Mental model: Read right to left. col-lg-4 means "4 columns wide on large+ screens." Below large, it falls back to the smaller class or stacks full-width.
05 Auto & Equal Columns

Don't want to do the math? Use .col (no number) and Bootstrap splits the space equally.

<div class="row">
  <div class="col">Auto</div>  <!-- 1/3 each -->
  <div class="col">Auto</div>
  <div class="col">Auto</div>
</div>

<!-- Mix: fixed + auto fills remaining -->
<div class="row">
  <div class="col-4">Sidebar</div>
  <div class="col">Main fills rest</div>
</div>
06 Spacing Utilities — Margin & Padding

Format: {property}{sides}-{size}

m = margin p = padding t=top b=bottom s=left e=right x = left+right y = top+bottom 0 to 5 (size) or auto 
mt-3    → margin-top: 1rem
px-4    → padding left+right: 1.5rem
mb-0    → margin-bottom: 0
ms-auto → margin-left: auto (pushes element right)
p-5     → padding all sides: 3rem
Trick: ms-auto on a flex child pushes it to the far right — great for nav buttons.
07 Display & Flexbox Utilities

Bootstrap uses flexbox under the hood. You can activate and control it with utility classes.

d-flex              → display: flex
justify-content-center  → center items horizontally
justify-content-between → space between items
align-items-center  → center vertically
flex-wrap           → allow wrapping
gap-3               → gap between flex children
<!-- Centered navbar example -->
<nav class="d-flex justify-content-between align-items-center p-3">
  <div>Logo</div>
  <div class="d-flex gap-3">
    <a>Home</a><a>About</a><a>Contact</a>
  </div>
</nav>
08 Common Gotchas
ProblemFix
Columns aren't side by side Make sure they're inside a .row inside a .container
Columns exceed 12 and look broken They'll wrap — this is intentional, but check your math
Layout looks fine on desktop, broken on mobile Add col-12 as the mobile default alongside your col-md-*
Horizontal scroll appearing A .row is missing its parent .container
Custom CSS fighting Bootstrap Link your CSS after Bootstrap's CDN link
